# Contributing

`gh-run-receptor` is a functional pre-1.0 preview. Read the
[developer-guide checkpoint](devguide/README.md) before proposing or writing code. It
contains the product boundary, provisional contracts, security model, test strategy, and
ordered roadmap needed to work without access to the original design conversation.

Follow [the development workflow](devguide/development_workflow.md) for environment,
testing, review, and definition-of-done rules. Repository-wide agent and contribution
constraints are in [AGENTS.md](AGENTS.md). Questions whose answer requires evidence are
tracked in [the decision register](devguide/decisions_and_open_questions.md); resolve the
applicable gate instead of silently choosing a permanent interface.

The most useful current contributions are broader sanitized corpus cases, generic CI and
documentation profiles, safe repository configuration, GitHub API compatibility tests,
schema review, and threat-model tests identified in
[the roadmap](devguide/development_roadmap.md).
